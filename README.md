# Writality Community Translations

Thank you to everyone helping make Writality more welcoming for writers around
the world.

This repository contains generated language-pack artifacts for Writality.
Edit translations in Crowdin, not in this repository.

Help translate Writality into French, Portuguese, or Spanish:
[https://crowdin.com/project/writality](https://crowdin.com/project/writality)

Translate naturally for writers and worldbuilders, not word-for-word. If
something feels unclear, leave a comment in Crowdin.

## Translation Notes

Keep Crowdin placeholders exactly as they appear in the English text. For
example, `{{name}}`, `{{count}}`, and `{{project}}` are filled in by Writality
while the app is running.

Good:

`Delete {{name}}?`

Bad:

`Delete name?`

You can move placeholders to fit your language, but do not translate, remove,
rename, or add spaces inside them.

## More Languages?

If you want to translate Writality into another language, please open an issue
so the language can be added to the Crowdin project.
